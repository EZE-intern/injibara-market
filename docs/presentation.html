Domain Context & Market Realities

The Regional Commerce Dilemma & What We Solve

Why generic Western e-commerce templates fail in Injibara — and our architectural trust platform.

⚠️ The Regional Marketplace Challenge
  • Rampant High-Value Fraud: Farmland (መሬት), Bajajs (ባጃጅ), and vehicles cannot be safely transacted via direct peer-to-peer chat without physical escrow and deed verification.
  • Informal Commerce Fragmentation: Local merchants operate through unorganized Telegram channels with zero inventory tracking, search discovery, or audit trails.
  • Payment & Network Realities: Reliance on Telebirr, CBE Birr, and Cash-on-Delivery, accompanied by 3G mobile latency and cloud cold-starts.
💡 The Injibara Market Solution
  • Domain-Aware Two-Tier Architecture: Algorithmically isolates everyday retail goods (direct seller chat/cart) from high-value brokered assets (admin mediated).
  • Verified Merchant Trust: Official Twitter/X-grade 12-point scalloped starburst rosette verified badge signaling merchant authenticity in Injibara.
  • Resilient Network Layer: Frontend Axios client automatically retries cold-start timeouts with exponential backoff and localized Ethiopian phone validation.

Core Algorithmic Innovation

Domain-Driven Two-Tier Brokered System

How client/src/utils/brokeredCategories.ts and server/src/utils/brokeredCategories.ts enforce mediated trust.

utils/brokeredCategories.ts 
// Bilingual pattern matching for high-risk assets
const BROKERED_CATEGORY_PATTERNS: RegExp[] = [
  /\bproperty\b/i, /\bland\b/i, /መሬት/,
  /\bvehicles?\b/i, /\bbajaj\b/i, /ባጃጅ/, /መኪና/,
  /\bheavy[\s_-]?machinery\b/i, /ማሽነሪ/
];

export function isBrokeredCategory(name, slug): boolean {
  const combined = `${name || ""} ${slug || ""}`.trim();
  return BROKERED_CATEGORY_PATTERNS
    .some(p => p.test(combined));
}
Tier 1 (High Value): Direct chat suppressed; inquiries auto-route to Admin Hub for physical appointment.
Tier 2 (Retail): Instant direct chat enabled; shopping cart & checkout active.

const ethiopianPhoneRegex = /^(\+251|0)(9|7)\d{8}$/;
